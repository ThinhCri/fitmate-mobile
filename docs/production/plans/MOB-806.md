Đọc contract-baseline.json và spec module đã VERIFIED; generate wire types, UI adapters giữ content fields.

## Trình tự
1. Settings map owner preferences/timezone và password/session actions; preserve server value khi save fail.
2. Support create/list/detail/reply với attachment private, distinguish queued/sent.
3. Delete/export require reauth, show retention/obligations/status; open public privacy/deletion pages.
## Tests và failure paths
Test export/download expired, repeated deletion, locked session, ticket owner mismatch, attachment error, logout clears cache và cancels inflight.
Mỗi screen có loading/empty/error/offline/permission/session-expired/disabled phù hợp.
Không announce mutation success trước server confirmation; retry key stable, stale response không overwrite state mới.
## Migration và rollback
Deletion irreversible backend không có undo giả. Support outage cho contact fallback đã cấu hình, không claim ticket submitted.
Profile/route/cache migration phải giữ data user và phân biệt legacy unknown, không đoán enum.
