1. Tạo API client/env validated và generated wire types; auth access in-memory/refresh secure storage single-flight.
2. Thay email routes/store keys bằng UUID/conversation ID qua adapters và clear account-scoped state.
3. Thêm verify/resend/forgot/reset/logout UI, xử lý locked/deletion/session expiry; loại password từ runtime persistence.
## Tests và failure paths
Test login→verify→refresh expiry, offline refresh, concurrent401 chỉ một refresh, logout while request pending, account A→B không leak cache/queue; production build không demo login.
Mỗi screen có loading/empty/error/offline/permission/session-expired/disabled phù hợp.
Không announce mutation success trước server confirmation; retry key stable, stale response không overwrite state mới.
## Migration và rollback
Rollback adapter chỉ với API revision compatible; không khôi phục plaintext password/mock auth. Session token cũ revoke khi schema/security thay.
Profile/route/cache migration phải giữ data user và phân biệt legacy unknown, không đoán enum.
