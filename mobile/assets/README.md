# Assets

Place icon.png, splash.png, adaptive-icon.png (PNG/SVG) here before first build.

For now `app.json` references these files but they are not required to commit
the foundation (MOB-001). Add them when running `npx expo prebuild` or first
build.

Suggested:
- icon.png: 1024x1024 PNG, transparent bg
- splash.png: 1242x2436 PNG (iPhone X portrait reference)
- adaptive-icon.png: 1024x1024 PNG, foreground only (background uses #FAFAF7)
